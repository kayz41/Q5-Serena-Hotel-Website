# Question 05 — Serena Hotel Kampala Booking Showcase

A single-page hotel room showcase and comparison practical using the burgundy, gold and ivory palette.

## Files
- `index.html` — sticky navigation, hero, room showcase, comparison table and booking section
- `booking.css` — external stylesheet

## Asset note
The HTML and CSS reference `serena-logo.png` and `hero-serena.jpg`. Those image files are not present in the original Question-05 folder, so they have not been fabricated. Add approved assets to this repository when available.

## Run locally
Open `index.html` in a browser.
